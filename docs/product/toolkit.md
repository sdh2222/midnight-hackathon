# Sourcenight toolkit

## This repo

- 이 기계에서 연다. 호스트된 사이트가 아니다.
- Midnight 지갑을 하나 만들고 주소만 보여 준다.
- 구매 한 건을 받는다. 품목, 수량, 단위, 배송 국가, 키워드, 필요 날짜는 Jev로 간다. 예산은 여기에 남는다.
- `commitRange`로 예산을 잠근 다음, TypeSafe 위의 Jev가 쿼리 하나를 고르고 순위를 매긴다.
- 고른 줄은 `commitVerify`로 검사하고, 목록에 Kept를 붙인다. 검사 결과는 Jev로 돌아가지 않는다.
- 로컬 에이전트는 없다. 화면이 필드를 나누고, API가 Jev를 부르고, prover가 예산을 검사한다.

## We will

- 버튼을 눌러 지갑을 만든다.
- Jev 키는 한 번 받고, 이 기계에만 둔다. 화면에는 다시 나오지 않는다.
- 구매 필드를 드래그한다. 순서는 우선순위다. 한쪽은 공개, 한쪽은 비공개다.
- 공개 쪽만 고정 프롬프트로 Jev에 보내 검색어를 만든다.
- 그 검색어로 쿼리한다. 페이지가 들어올 때마다 Jev가 순위를 매기고, 매퍼가 매핑하고, Midnight이 비공개 값과 검사한다.
- 랭커는 좌우 두 칸이다. 들어오는 줄이 쌓이고 순서가 바뀐다. 오른쪽은 Midnight이 통과시킨 줄이다.
